# 手机现场展示

网站：https://cville-ai-woven.sifanye-ghost.chatgpt.site

1. 提前在手机打开网站。开场展示首页的丝线主视觉。
2. 滚到 Build / Learn / Share，依次点击。说明三个入口分别对应动手、学习、分享。
3. 展示活动时间表和 “What if I don’t have a laptop?”，强调真实的新手体验。
4. 展示 Field Notes 与 Studio IX 的 Why the threads?，说明设计来自当地历史和真实社区活动。
5. 页脚点击 **Take this with you**，让对方扫码，或复制网址。
6. **Behind the threads** 页面包含设计解释、来源和英文讲稿，可以直接给主办者看。

要明确说这是提前准备的 concept，现场继续和小组一起参与。报名仍通过官方 Meetup。

## 60-second English introduction

“I started with the place. The Ix neighborhood used to make textiles. Now it brings people and ideas together. So I built this redesign around a woven thread.

The home page tells you who this community is for and how to join the next meetup. Build, Learn, and Share give you three ways to explore. Each thread leads to something real: a gathering, a learning opportunity, or a conversation.

I used AI to help research, design, and build it, then checked the facts and the interactions. It works on a phone, because participating shouldn’t depend on owning a laptop.

This is my pre-event concept. I’d love to see which ideas we can take further together.”

## If they ask about the build

- Tool: Codex, plus OpenAI image generation for the original abstract artwork.
- Approach: research the real brief → establish a local visual idea → build → check facts and interactions.
- Stack: plain HTML, CSS, and JavaScript; no framework or runtime AI API dependency.
- Takeaway: AI benefits from specific context. The details still need editorial and usability judgment.
